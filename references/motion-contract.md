# 运动参数与验收

模板来自「小小善意」样片，并沿用红色「崩裂高塔」的交互与入场结构。无文字版本只移除文本信息、文案逻辑与滑块界面；深度默认值仍为 2.6，轮廓光默认值仍为 0.8。

| 项目 | 基准 |
| --- | --- |
| 卡牌 | 2:3；最大宽 445px，按视口高度收缩，完整显示牌框 |
| 舞台 | `perspective:1700px`，整个舞台接收鼠标 |
| 翻牌 | 2.25 秒，从 `rotateY(-175deg)` 翻入，有一次轻微过冲 |
| 事件 | 2.45 秒开始主题事件，2.55 秒出现扩散光 |
| 主体 | 4.25 秒显现时间轴；4.3 秒进入可交互定格 |
| 整牌 | 水平 ±21°、垂直 ±16°，平移 ±10/8px |
| 背景 | x/y 为 `-7/-6 × depth` 像素，反向轻移，预留超出画面的覆盖区 |
| 前景 | x/y 为 `13/13 × depth` 像素，`translateZ(80px)`；机器人示例基准缩放 `.92`，按新图边界调整 |
| 空间与阴影 | 卡面容器保留 `preserve-3d`，不在它上面用 clip-path 压平前景；卡框厚度 8px，底板独立圆角裁切；主体轮廓投影位于底板上方 3px，随指针轻微反向变化 |
| 人物光照 | 同一透明主体遮罩控制动态明暗及柔和高光；不复制另一张可见的人物。指针以未变换的卡牌几何归一化，避免随旋转反馈漂移 |
| 材质 | 透明主体复制层仅做轮廓光，遮罩扫光沿用同一透明主体图 |
| 重播 | 清理计时器，归零姿态，重启动画，4.3 秒后再允许交互 |

复制 `assets/card-template.html` 后，三个样例素材默认位于它旁边的 `example/` 目录。更换图片时修改相应 URL；`original.png` 是原画存档，背景与前景分别来自 `background.png`、`foreground.png`。CSS 中保留 `tower-depth` 等类名是为了复用已确认的运动逻辑，实际主体不限于高塔。

验收应覆盖：

1. 原图、背景与前景尺寸一致；透明主体存在真正的全透明区，背景补画完整。
2. 开场翻牌、事件爆发与定格清楚可见；重播两次节奏相同，定格不自动倒转。
3. 指针在舞台四角时整牌、前景、背景分别运动，主体始终处于牌框内。
4. 鼠标不必悬停主体即可产生视差；触控拖动工作，低动态模式保留完整主体。
5. 卡牌与图标按钮在窄屏可见。不存在标题、幸运星或其他文案；辅助技术标签仍可识别重播按钮。
